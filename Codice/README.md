# README 

This README provides an overview of all the files and their purposes within the project directory for the Advanced Machine Learning submission.

## Project Contents

The project directory contains the following files and folders:

## Notebooks (to be executed in the listed order):
1.	Code
	-	Allows the use of GloVe or EgoVLP as feature extraction methods.
	-	Includes data analysis with plot generation.
	-	Facilitates training with the option to choose between BERT and GloVe models.
2.	Narration
	-	(Details for this file are missing—consider adding a description).
3.	Gemma
	-	Used to generate the dataset via GEMMA.
4.	FineTuning
	-	A simplified version of the Code notebook.
	-	Focuses on fine-tuning the model.
	-	Includes pretraining using queries generated from the Gemma notebook.
	-	Automatically downloads the dataset generated by the team.

## Folders
1.	combine
	-	Contains scripts to merge multiple narration files, as narrations were generated simultaneously using multiple accounts in GEMMA.
2.	clean
	-	Holds cleaned datasets and intermediary files for processing.

## Additional Files
	-	analyze_data.py
	-	A script used for analyzing narration files.
